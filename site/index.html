How it works

  
Three crossings, three tricks.

  
    
      
  1. Reuse
    Read a shared prompt once
    Coding agents send the same system prompt and tool definitions with every session. Arf keeps the model's state at the end of that shared part, so the next session starts after it.
    2. 
      
  2. Guess
    Propose seven, check them in one pass
    A small draft model guesses the next seven tokens. The big model checks all of them in a single pass and keeps the ones it agrees with, so one pass can produce several tokens.
    3. 
      
  3. Share
    Many conversations, one pass over the weights
    Requests that arrive together decode together: each step reads the weights once for every active conversation, and a new request joins without waiting for the others to finish.
    4.

Models

  
The models it runs.

  
Text, pictures, video and sound in; text and pictures out — on the Mac's GPU, through the same OpenAI and Anthropic APIs.

  
    
    
  • Images
    Reads a picture
    Qwen3.8's vision encoder runs on the GPU: a 512×384 image in ~0.3 s. Gemma 3 sees too.
    image_url · Anthropic image
    • 
    
  • Video
    Watches a clip
    Frames are sampled with ffmpeg and read by the same encoder, at the rate you ask for.
    video_url · fps · max_frames
    • 
    
  • Audio
    Listens
    Qwen3-Omni takes speech and sound as input, wav or mp3, and answers in text.
    input_audio
    • 
    
  • Text to image
    Draws
    FLUX schnell turns a prompt into a picture, on the GPU, from the same server.
    /v1/images
    • 
  

  
Image and video answers decode without the draft. Speech output is not built yet.

The name

  
In 1959 Cahit Arf gave a public lecture titled “Can a machine think, and how can it think?”

  
Cahit Arf (1910–1997) was a Turkish mathematician: the Arf invariant, Arf rings, the Hasse–Arf theorem. His lecture came nine years after Turing asked the same question. The mark is a trefoil, the simplest knot whose Arf invariant is 1.
